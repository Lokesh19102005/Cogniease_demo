# CogniEase company website

A dependency-free, responsive company website for CogniEase Techno Labs Pvt. Ltd. and its current product, TARU.

## Run locally

In PowerShell, run `Start-Process .\index.html` from this folder. The site uses local HTML, CSS, JavaScript, and SVG; it does not require a package install or build step.

## Contents

- `index.html` — company story, challenge and research context, TARU features, and portal links
- `styles.css` — responsive layout, design system, and reduced-motion support
- `script.js` — accessible mobile navigation and current-year footer
- `favicon.svg` — CogniEase mark

## Research findings

The site presents selected aggregate, self-reported results from CogniEase’s Business Requirement Mapping report (April 2026, n=221). It labels the sample and source and explains that the findings describe these respondents, not every student or campus. The displayed figures cover help-seeking, anonymous check-ins, trust, campus mood reports, and perceived institutional awareness.

The source PDF belongs in the ignored `private-research/` folder and is excluded from Git-based deployments. Do not add the report or individual respondent data to the public site. The site makes no claim that the results represent every Indian college or that TARU produces clinical outcomes.
