# CogniEase website

A dependency-free, responsive company website for CogniEase Techno Labs Pvt. Ltd. and its current product, TARU.

## Run locally

Open `index.html` in a browser. The site uses local HTML, CSS, JavaScript, and SVG assets; it does not require a package install or build step.

## Contents

- `index.html` — page content and inline interface illustrations
- `styles.css` — responsive layout, visual design, and reduced-motion support
- `script.js` — accessible mobile navigation and current-year footer
- `favicon.svg` — CogniEase mark

## Notes

- The institution portal section lists only Individual Mood Insights, Collective Mood Insights, and Campus Problems.
- Portal links point to the TARU URLs supplied for this project.
- No company email, phone number, address, confidential survey figures, or unverified outcome claims are included.
